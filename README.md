# SSX 3 VR

A fan-made VR adaptation of SSX 3 for Windows, built on the [native PC port](https://github.com/andersfischernielsen/ssx3-decomp).

Play with the original third-person chase camera and a gamepad. Your rider stays visible, and head tracking lets you look around the course while riding. The project uses the existing gameplay, courses, characters, music and save system. The regular desktop version remains available.

Features include:

- Stereo 3D rendering and head tracking through SteamVR.
- Gamepad controls for riding, tricks and menus.
- Floating panels for menus and race information.
- The original game’s audio and saves.

You will need:

- A Windows PC capable of running SteamVR.
- A compatible VR headset, with SteamVR selected as the OpenXR runtime.
- A gamepad. Xbox-compatible controllers are recommended. VR motion controllers are not currently supported.
- Your own disc image of **SSX 3 for PlayStation 2, USA version** (`SLUS-20772`).

Download the latest release from this repository’s **Releases** page. See [setup and launch instructions](README-VR.md) and [available settings](docs/options.md).

Bug reports and contributions are welcome. When reporting a problem, include your headset, graphics card, course and a description of the issue. See [the development guide](docs/development.md) for contributing.

This project builds on the work of [Anders Fischer-Nielsen and the SSX 3 port contributors](https://github.com/andersfischernielsen/ssx3-decomp), with decompilation reference work from [DevvyDont/ssx3](https://github.com/DevvyDont/ssx3).
